# Проект приюта-питомника для собак

Данный проект включает в себя 3 основных приложения:
1) Работа с питомцами
2) Личный кабинет пользователя
3) Работа с отзывами

Виртуальное окружение используемое для проекта: venv

1) После настройки виртуального окружения установите зависимости из файла requirements.txt
```bash
  pip install -r requirments.txt
```

2) Заполните файл .env согласно .env_sample
3) Создайте Базу данных (MSSQL) при помощи команды: 
```bash
  python manage.py ccdb
```
4) Создайте миграции при помощи:
```bash
  python manage.py makemigrations
```
5) Проведите миграции:
```bash
  python manage.py migrate
```
6) Выполните команду для создания пользователя с разным уровнем доступа
```bash
  python manage.py ccsu
```
7) Выполните команды для заполнения БД используя фикстуры:
```bash
  python manage.py loaddata dogs.json
  python manage.py loaddata reviews.json
```
8) Запустите проект при помощи 
```bash
  python manage.py runserver
```

Модели используемые в проекте:

Dogs с полями:
- name - Кличка;
- breed - Порода;
- photo - Фотография;
- birth_date - Дата рождения;
- is_active - Активность;
- owner - Хозяин;
- views - Просмотры

Reviews с полями:
- title - Заголовок
- slug - URL
- content - Наполнение
- created - Дата создания
- sign_of_review - Признак отзыва 
- author - Создатель
- dog - Питомец

Users с полями:
- email - Почта
- role - Роль
- first_name - Имя
- last_name - Фамилия
- avatar - Аватар
- phone - Телефон
- telegram - Телеграм
- max_messenger - Макс
- is_active - Статус

Расширения (Ролевая модель):
- Реализованы кастомные решения для пользователя с ролью MODERATOR
- Смотреть списки пород, собак и отзывы могут все пользователи
